## 主题介绍（AI 编写）

本仓库提供一套 **Clash Verge 自定义 CSS 主题**，整体风格偏 **高级磨砂 / 玻璃质感**，针对 **macOS（Clash Verge for mac）** 的界面结构与渲染效果进行适配与优化。

> **说明：本主题由 AI 辅助编写与迭代。**

---

## ✅ 支持平台

- **macOS：支持（推荐）**

---

## ❌ 不支持平台

- **Windows：不支持**  
  Windows 端由于界面结构与渲染差异（部分 CSS 选择器、毛玻璃效果、控件表现等不一致），可能出现样式失效或观感偏差，无法保证效果与截图一致，因此本主题 **不提供 Win 适配**。

---

## 使用方法

1. 打开 Clash Verge
2. 进入 **主题 / 外观 / 自定义 CSS**（入口名称可能略有不同）
3. 将本仓库提供的 CSS **完整复制粘贴**进去并保存/启用即可
