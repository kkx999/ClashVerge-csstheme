## ✨ Apple-like Premium Glass（苹果高级感毛玻璃主题）

灵感来自 macOS 的 **Vibrancy / Frosted Glass（半透明材质）**：低饱和、柔和渐变背景、克制阴影与细边框（hairline），让界面通透但不刺眼，整体更接近“苹果式高级感”的干净与精致。  
同时针对实际使用体验做了优化：侧边栏保持单列更符合默认习惯，节点选中态仅保留整块蓝色高亮，观感更清爽；并修复窗口圆角处可能出现的底色露出（黑边）问题，使整体更统一。

## 🚀 使用方法（Clash Verge）

1. 打开 **Clash Verge** → **设置** → **主题 / 自定义 CSS**（或同类入口）
2. 打开本仓库里的 CSS 文件，**复制全部内容**
3. 粘贴到 Clash Verge 的主题 CSS 输入框/自定义样式区域
4. 保存并刷新（必要时重启 Clash Verge）

> 提示：若软件更新导致部分样式失效，通常是界面生成类名变化，可通过更新选择器适配。
